## 🚀 How to run this portfolio app locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set your environment variables in `.env` (like `VITE_WEB3FORMS_ACCESS_KEY` for contact form).
3. Run the app:
   ```bash
   npm run dev
   ```
